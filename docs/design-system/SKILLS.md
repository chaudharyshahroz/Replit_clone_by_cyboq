# Built-in Design Skills

`REKLU_DESIGN_SKILLS` is a typed registry. Every entry declares industries, capabilities, incompatibilities, priority, and binding rules. `routeDesignSkills` always activates premium composition, brand, art direction, design-system, responsive, accessibility, and visual-critic skills, then adds only relevant vertical skills.

Examples:

- hospitality + commerce: Hospitality, Editorial, E-commerce, Conversion;
- developer tool: Developer Product and SVG Illustration;
- fintech: Finance and trust-oriented brand rules;
- portfolio/agency: Editorial and Portfolio;
- user references: Reference Analysis.

Inactive skills must not leak unrelated visual patterns into a build. The selected skills are persisted with the project and shown in build diagnostics.
